CREEPER ZZ - Android starter project

WHAT IS INCLUDED
- Android WebView wrapper project
- Offline HTML app bundled in app/src/main/assets/index.html
- Sensitivity sliders and starter presets
- Fire button size and aim precision selector
- Aim practice tap-target simulator with score and hit-rate
- Headshot practice guide
- Black + red responsive UI

BUILD APK
1. Install Android Studio on a computer.
2. Open Android Studio -> Open -> select the Creeper_ZZ folder.
3. Allow Gradle sync and install any SDK components Android Studio requests.
4. Select Build -> Build Bundle(s) / APK(s) -> Build APK(s).
5. When build completes, choose Locate. The debug APK is usually at:
   app/build/outputs/apk/debug/app-debug.apk
6. Transfer the APK to your Android phone and install it. Android may ask you to allow installs from that source.

NOTES
- This is a starter project, not a signed Play Store release.
- To publish, create a signed release build in Android Studio.
- This app is an independent practice/settings tool. It does not modify Free Fire,
  automate gameplay, access accounts, or provide cheats.
- Sensitivity values are suggestions; test and adjust them for your device.
